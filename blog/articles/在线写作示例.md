# 在线写作示例

本文档演示如何通过网站的 **在线写作入口**（`/blog/admin/`）发布一篇新文章，并上传配图到 `blog/images` 目录。

---

## 一、准备 GitHub Token

在线写作页面会直接调用 GitHub API 写入仓库，需要你先创建一个 **Personal Access Token**。

### 1. 创建 Token（推荐细粒度）

1. 打开 GitHub → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens**。
2. 点击 **Generate new token**。
3. 填写：
   - **Token name**：例如 `blog-write-hujianbest-io`
   - **Expiration**：按需选择（如 90 天）
   - **Repository access**：选择 **Only select repositories**，勾选 `hujianbest/hujianbest.github.io`
   - **Permissions** → Repository permissions：
     - **Contents**：**Read and write**（必须，用于创建/更新 `blog/articles/*.md` 和 `blog/images/*`）
     - **Metadata**：**Read-only**（默认即可）
4. 点击 **Generate token**，复制生成的 token（形如 `github_pat_xxx`），**只粘贴到写作页面使用，不要提交到代码库**。

### 2. 若使用经典 Token（Classic）

- 打开 **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**。
- 勾选权限 **repo**（或至少该仓库的写权限）。
- 生成后复制 token（形如 `ghp_xxx`）。

## 二、在写作页面发布一篇文章

### 1. 打开写作页面

- 本地预览：`http://localhost:xxxx/blog/admin/`
- 线上：`https://hujianbest.github.io/blog/admin/`

### 2. 配置仓库与 Token（首次使用）

在左侧 **「仓库配置与文章信息」** 面板中：

| 字段 | 示例值 | 说明 |
|------|--------|------|
| GitHub Personal Access Token | `github_pat_xxx` 或 `ghp_xxx` | 粘贴你在上一步复制的 token |
| 仓库 Owner | `hujianbest` | 本仓库的 GitHub 用户名 |
| 仓库名 | `hujianbest.github.io` | 本仓库名 |
| 分支 | `main` 或 `master` | 你实际使用的默认分支 |

点击 **「保存配置到本地」**，下次打开页面会自动带出（Token 仅存在当前浏览器本地）。

### 3. 填写文章信息

| 字段 | 示例 |
|------|------|
| 文章标题 | `在线写作示例` |
| 文件名（可留空） | `在线写作示例.md` 或留空（将用标题生成） |
| 发布日期 | `2025-03-09` |
| 标签（逗号分隔） | `博客, 写作, 示例` |
| 分类 | `工程实践` |

### 4. 撰写 Markdown 正文

在中间 **「Markdown 正文」** 输入框中写内容，例如：

```markdown
## 为什么要用在线写作？

有时在办公室或平板上，没有本地 Git 环境，仍希望快速发一篇笔记。
在线写作页面会通过 GitHub API 直接把内容写入仓库，无需 `git push`。

## 插入图片

若在「文章图片」里选择了本地图片，发布时会自动上传到 `blog/images/`。
在正文中引用即可：

![](../images/demo-screenshot.png)

发布后，GitHub Pages 更新后即可在博客中看到新文章与图片。
```

### 5. 上传配图（可选）

- 在右侧 **「文章图片」** 处点击选择文件，可多选。
- 选中的文件会列在下方，并提示引用方式：`![](../images/文件名)`。
- 发布时，这些图片会按**原文件名**上传到 `blog/images/`；若需要在正文里引用，把上面的引用复制到 Markdown 中对应位置即可。

### 6. 发布

- 点击 **「发布到 GitHub」**。
- 页面会先提交 `blog/articles/在线写作示例.md`（带自动生成的 Front Matter），再依次提交你选择的图片到 `blog/images/`。
- 成功后会显示类似：`发布成功：blog/articles/在线写作示例.md，上传图片 1 张。`

### 7. 让新文章出现在侧边栏和首页

- **侧边栏**：编辑 `blog/_sidebar.md`，在合适位置增加一行，例如：
  - `* [在线写作示例](articles/在线写作示例)`
- **首页「最近文章」**：编辑 `blog/README.md`，在「最近文章」小节增加一条，例如：
  - `### [在线写作示例](articles/在线写作示例)`
  - `发布日期：2025-03-09`
  - `本文演示如何通过在线写作页面发布文章并上传图片。`
- 保存后执行 `git pull`（若在线写作已提交）或直接本地修改后 `git add`、`git commit`、`git push`，GitHub Pages 更新后即可在首页和侧边栏看到新文章。

---

## 三、发布后的文章长什么样？

发布成功后，仓库中会新增（或更新）例如：

**`blog/articles/在线写作示例.md`**（头部由页面自动生成）：

```markdown
---
title: "在线写作示例"
date: 2025-03-09
category: "工程实践"
tags: ["博客", "写作", "示例"]
---

## 为什么要用在线写作？
...
```

**`blog/images/demo-screenshot.png`**（你选择的图片会按原文件名存放在此目录）。

在博客中访问 `/blog/#/articles/在线写作示例` 即可阅读；正文里的 `![](../images/demo-screenshot.png)` 会正确显示图片。

---

## 四、安全提醒

- Token 仅保存在**当前浏览器**的 `localStorage`，不会上传到本站服务器，也不会出现在仓库里。
- 建议使用 **Fine-grained token**，且只勾选本仓库、只给 **Contents: Read and write**，用完可随时在 GitHub 后台撤销。
- 若使用公用电脑，离开前可在写作页面清空 Token 或使用浏览器无痕模式。
